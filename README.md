# PurrCatMet — сборки

Здесь лежат только готовые сборки PurrCatMet. Кнопка «Обновить» в программе берёт новые версии отсюда.

**Скачать:** справа **Releases** → последняя версия:

- `PurrCatMet-windows.zip` — распакуй и запусти `PurrCatMet.exe`. Python, ffmpeg и ExifTool уже внутри.
  Если Windows покажет синее окно SmartScreen — «Подробнее» → «Выполнить в любом случае».
- `PurrCatMet-mac-apple-silicon.zip` — Mac на M1–M4, `PurrCatMet-mac-intel.zip` — Mac на Intel.
  Первый запуск — правый клик → «Открыть».
